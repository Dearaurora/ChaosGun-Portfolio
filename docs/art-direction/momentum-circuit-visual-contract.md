# Momentum Circuit 正式视觉合同 v2

状态：冻结。该合同约束正式地图的静态资产、动态机制演出和云层背景；不得改变已验证白模轮廓、碰撞、孔洞、掩体或出生点。

## 参考图语义

- 正式构图参考：`docs/art-direction/references/momentum_circuit/momentum_circuit_gravity_side_swap_cloud_vortex.png`。
- 白模布局与 `resources/maps/momentum_circuit_layout_v1.json` 是几何权威来源。
- 概念图中的角色、弹道、弹壳、黄色坠落角色、右侧暖色铺色和大型重复箭头均属于玩法说明层，不是地图资产。
- 正式实现必须保留平台、三个孔洞、九组掩体、四个青色稳定锚点、三个橙色射击节点、横向伪重力机制和双层云涡。

## 机制演出合同

- `IDLE`：右侧台面必须保持与全图一致的中性色；无方向流线、无边界脉冲、无地面覆盖、无箭头。
- `WARNING`：入口处细窄分段边界脉冲；右侧外沿追光开始；少量流线出现；播放预警音。
- `ACTIVE`：不显示边界分割；使用稀疏青色水平流线和暖色外沿追光表达方向；播放生效音。
- `REVERSING`：流线完全熄灭，边界短促闪烁，随后以相反运动方向重启；播放反转音。
- `RECOVERY`：流线、外沿追光和声音尾部逐渐衰减。
- 禁止任何状态创建覆盖右半区的半透明面、道路标线式箭头、教程覆盖层或硬直的半图染色。
- 方向必须由运动方向、节奏、声音和空间位置共同表达，不得只依赖颜色。

## 节点与锚点反馈

- 三个橙色节点保留为真实玩法对象；VFX 必须区分就绪、全局防连击、单节点冷却、接受命中和拒绝命中。
- 四个青色圆盘只作为稳定锚点，不得恢复传送语义。
- 锚点外圈应低调；角色进入稳定区时才加强核心环和光柱，并播放稳定反馈音。

## 分层所有权

- `Gameplay`：唯一碰撞、伪重力控制器、节点、锚点、出生点和武器刷新。
- `ForegroundVisuals`：仅静态平台、掩体、节点/锚点底座和材质；无碰撞、灯光、相机、角色或动态机制状态。
- `MechanismVFX`：仅细窄边界脉冲、右侧外沿追光、稀疏方向流线、节点/锚点反馈和机制音频。
- `Backdrop`：双层反向慢旋云涡，无碰撞、无投影、不得遮挡玩法轮廓。

## 验收门禁

1. `1536×1024` 的 `IDLE` 与 `ACTIVE` 截图中，平台台面不得出现右半区暖色填充或任何箭头。
2. `ACTIVE(+X)` 与 `ACTIVE(-X)` 必须通过流线运动方向和外沿追光方向可区分；静态单帧不强制出现符号。
3. `REVERSING` 截图中流线必须熄灭；`WARNING` 只允许细窄分段边界提示。
4. VFX 调试契约必须报告 `surface_fill_present=false`、`literal_arrow_count=0`、一个边界提示、至少一条流线和至少一个外沿段。
5. 空地图、四人战斗、HUD 安全区、六种机制状态和云涡运动证据均需重新捕获。
6. 白模 IoU、机制、运行时、AI、地图池和 Forward+ 性能门禁不得回退。
