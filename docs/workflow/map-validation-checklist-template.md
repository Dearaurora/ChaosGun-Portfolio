# Map Validation Checklist

## Connectivity
- [ ] Center reaches every side island.
- [ ] Any side island can route into another zone without only backtracking.
- [ ] No primary route becomes a dead-end corridor.

## Fall Risk
- [ ] Gaps read clearly as lethal space.
- [ ] Bridges have real drop zones on both sides.
- [ ] Main island has outer ledges that support ring-out finishes.
- [ ] No fake cliff edges that look dangerous but are actually safe.

## Spawn And Tempo
- [ ] Every spawn area has at least two usable exits.
- [ ] Spawns are not instantly pinched by a single bridge choke.
- [ ] Runtime respawn points match the map-specific spawn plan.
- [ ] Respawn points land on valid playable surfaces.
- [ ] Opening movement reaches first contact quickly without instant point-blank collisions.
- [ ] Pressured players have a route swap option.

## Readability
- [ ] Default camera framing makes the main island obvious.
- [ ] Runtime camera behavior matches the map's intended framing policy.
- [ ] Main bridges and riskier side bridges are readable at a glance.
- [ ] Bridge mouths are free of large blockers.
- [ ] Main fight space and danger edges are visually distinct.

## Combat Value
- [ ] Center is important but not the only valuable fight location.
- [ ] Flank paths create real reposition opportunities.
- [ ] Most ring-out finishes happen near bridges, ledges, or island edges.
- [ ] No area functions as a low-risk bunker.

## Resource Spawns
- [ ] Weapon or pickup spawn points land on valid playable surfaces.
- [ ] Resource spawns do not appear in lethal gaps or unreachable spots.
- [ ] Resource placement supports the intended route and fight rhythm.

## Runtime Smoke
- [ ] An automated smoke run or live playtest has been completed for the current pass.
- [ ] Weapon or pickup cadence engages early enough for the target combat tempo.
- [ ] Concurrent weapon or pickup presence matches the intended fight pressure for the map.
- [ ] Concurrent weapon or pickup presence spans the intended route zones for the map.
- [ ] The map produces meaningful eliminations or ring-out pressure during the smoke window.
- [ ] Variance-sensitive tuning decisions are based on a multi-run smoke batch, not a single sample.
