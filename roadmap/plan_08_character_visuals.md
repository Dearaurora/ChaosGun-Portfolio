# 计划 08：角色视觉改进

## 目标描述

当前所有角色都是单色胶囊体（玩家 = 粉红色，AI = 绿色，靶子 = 默认色）。没有武器模型、没有朝向指示器，视觉辨识度低。

## 拟议变更

### 短期方案：几何体组合（无需外部美术资源）

#### [MODIFY] `scenes/characters/player.tscn`

用多个基础 Mesh 组合出更有辨识度的角色：
- **身体**：保持胶囊体但缩小
- **头部**：在胶囊体顶部添加一个 SphereMesh
- **枪指示器**：在 WeaponPoint 处添加一个细长的 BoxMesh 表示枪管（朝前方）
- **方向指示器**：在脚下添加一个三角形 Mesh 或箭头指向面朝方向

#### [MODIFY] `scenes/characters/ai_character.tscn`

同上，但使用不同颜色方案以区分：
- 多个 AI 可以用不同颜色（蓝、紫、橙等）
- 可以通过 `@export var color: Color` 在场景中配置

#### [MODIFY] 场景中的材质

使用 `StandardMaterial3D` 的特性增加视觉效果：
- 加 `emission` 使角色在暗环境中可见
- 加 `rim` 效果增加轮廓感

### 长期方案：3D 模型（需外部资源）

- 使用 Blender 制作简单的低多边形角色模型
- 或使用 Kenney.nl 等免费资源库的现成模型
- 添加简单的动画（跑步、射击、死亡）

## 待定问题

> [!IMPORTANT]
> 1. **优先短期方案还是直接做模型？** 几何体组合可以快速改善视觉，作为过渡方案。
> 2. **角色风格定位**：写实？卡通？像素？低多边形？这决定了长期的美术方向。
> 3. **是否需要区分不同 AI？** 如果未来有多个 AI，是否每个有独特外观？

## 验证方案

### 手动验证
1. 运行游戏，确认新的角色外观正确渲染
2. 确认枪管/方向指示器跟随角色旋转
3. 确认碰撞体大小与视觉匹配
4. 确认在不同角度下角色易于辨识
